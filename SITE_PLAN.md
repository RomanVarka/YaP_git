# План MVP B2B-портала для закупок в FMCG

## Разделы сайта
1. **Главная (`index.html`)** – краткое описание портала и навигация.
2. **Каталог поставщиков (`catalog.html`)** – карточки поставщиков с фильтрами и поиском.
3. **Страница поставщика (`supplier.html`)** – подробная информация, рейтинг и контакты.
4. **Динамика цен (`prices.html`)** – график цен по ключевым категориям.
5. **Аналитика (`analytics.html`)** – список отчётов и материалов.
6. **Вход (`login.html`)** – форма авторизации.

## Структура данных
- `scripts.js` содержит тестовые данные поставщиков и функции рендера.
- В будущем данные можно загрузить из API или базы данных.
